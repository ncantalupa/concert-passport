# Concert Passport — GitHub Pages

This folder is a complete static website. It does not require npm, React, a database, or a build command.

## Upload

Upload these files to the root of a GitHub repository:

- index.html
- styles.css
- app.js
- og.png
- favicon.svg

Do not upload the ZIP itself. Extract it first.

## Publish

1. Open the repository on GitHub.
2. Select **Settings**.
3. In the left sidebar, select **Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
5. Choose the **main** branch and **/(root)** folder.
6. Select **Save**.

GitHub will display the published URL after deployment finishes.

## Updating the site

Edit or replace the files in the repository and commit the changes. GitHub Pages will republish automatically.
